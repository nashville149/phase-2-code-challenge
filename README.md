# Smart Goal Planner
A React + Vite fintech app to manage multiple savings goals. Users can create, update and delete
## Features
- Add new financial goals (e.g., Travel Fund, Emergency Fund)
- Update goal details: name, target amount, category, deadline
- Delete goals
- Track savings progress with visual progress bars
- Make deposits to any goal
## Project Structure
-smart-goal-planner- React + Vite frontend app
-db.json- JSON data file serving as the backend database
-json-server 
# Getting Started
Prerequisites
- Node.js and npm installed
- npm install -g json-server
